Utiliser la clé de secours

Cette clé donne tous les droits. Au quotidien, utilisez un compte avec un rôle limité.

Les sessions expirent automatiquement. Le premier compte se crée avec ZARMA_BOOTSTRAP_ADMIN_USERNAME et ZARMA_BOOTSTRAP_ADMIN_PASSWORD. HTTPS est obligatoire en dehors d’un poste local.

Écouter et valider

Écoutez l’audio, corrigez la transcription si besoin, puis choisissez pour quelle tâche la prise est utilisable : reconnaissance (ASR), synthèse (TTS) ou les deux. La parole libre ne peut pas être validée pour la synthèse.

Connectez-vous pour afficher les enregistrements.

Textes à enregistrer

Importez seulement des textes relus et approuvés par un locuteur compétent. Les lignes en attente ou avec un marqueur provisoire (TO_VERIFY, TBD, PENDING_RIGHTS_REVIEW) sont refusées. L’application n’invente aucun texte.

Volontaires

Vue par code pseudonyme, limitée à votre périmètre. Aucun nom, numéro de téléphone ni contact n’est affiché.

Exporter le corpus

Archive ZIP avec les fichiers WAV (mono, PCM 16 bits, fréquence fixée par le serveur) et un fichier metadata.csv. Seuls les enregistrements validés pour la tâche choisie sont inclus.

Avant l’entraînement, vérifiez le consentement, les droits, les transcriptions et la séparation train, validation et test.

Datasets préparés

Créez une release à partir des enregistrements validés, préparez-la sur le serveur avec scripts/prepare_release.py, inspectez le rapport qualité, puis approuvez-la après contrôle des transcriptions, des droits et des partitions.

Entraînement

Un run part toujours d’une release approuvée. Cette page journalise le run ; elle ne lance pas de calcul distant automatiquement.

Serveurs de calcul

Serveur local avec GPU, SSH, Slurm, notebook, GPU dans le cloud ou API gérée. Aucun secret n’est stocké ici : seul le nom d’une variable d’environnement est conservé.

Comptes de l’équipe

Chaque compte ne reçoit que les tâches nécessaires. Les langues et régions attribuées limitent ce que la personne voit. Les volontaires n’ont pas besoin de compte.

Langues et régions sont obligatoires pour tous les rôles sauf admin.

Journal d’audit

Changements de comptes, imports, releases, serveurs et runs. Les détails ne doivent contenir ni secret ni donnée personnelle inutile.

Retirer les données d’un participant

À utiliser seulement après avoir vérifié la demande et le code transmis par le participant selon la procédure convenue. La suppression touche la base et l’audio du stockage actif.

Le journal garde le motif, la personne responsable et le nombre de fichiers supprimés, mais pas le code participant. Les sauvegardes, les exports déjà téléchargés, les copies partagées et les modèles déjà entraînés ne sont pas touchés.
